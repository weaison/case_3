# Блог

Учебный проект — блог на чистом HTML, CSS и JavaScript.
Работает без сервера, данные хранятся в localStorage.

## Возможности

- Регистрация и вход пользователя
- Создание поста
- Редактирование и удаление своего поста
- Три режима видимости: публичный, скрытый (по ссылке), приватный
- Теги: добавление и фильтрация
- Сортировка постов по дате и заголовку
- Комментарии к постам
- Подписки на пользователей
- Персональная лента на основе подписок
- Просмотр профиля пользователя с его публичными постами

## Запуск

Открыть `index.html` в браузере.

## Учётные записи

- Админ для тестов: `admin` / `admin123`
- Обычный пользователь: зарегистрироваться через форму

## Хранение данных

Все данные хранятся в localStorage под ключом `blog_db`.
Сброс: DevTools → Application → Local Storage → удалить `blog_db` → перезагрузить.

## Структура

- `index.html` — разметка
- `style.css` — стили
- `app.js` — логика приложения (роутинг, работа с данными, рендер)
